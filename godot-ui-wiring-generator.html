FREE WEB TOOL / GODOT 4

UIシグナルの
配線コードを生成

Buttonと子ノードのパスを入力すると、キーボード・コントローラーのフォーカス、押下、効果音、視覚フィードバックをつなぐGDScriptを生成します。アドオンやアップロードは不要です。

入力内容はこのページ内だけで処理し、保存・送信しません。生成対象はGodot 4.7.2とAlien AlpacaのSelectionFeedback / MenuFeedback APIです。Godot標準のシグナル接続機能を置き換えるものではありません。

01 / GENERATOR

シーンのNodeパスを入力

Node名は英字または_で始め、英数字と_を使って「親/子」の形で入力します。スクリプトを付けるControlからの相対パスです。

    同じシグナルをInspectorや別スクリプトですでに接続している場合は、二重発火を避けるため既存接続を確認してください。Node名を変更したら再生成します。
    
        
    
      
    

      
    
        
    02 / SCOPE
    
        
    生成するものと、しないもの
    
        
    
          
    生成する
    • 3シグナルの接続
    • 選択・成功または無効表示
    • 2種類のAudioStream割当口
    • 動きを減らす設定とclear関数
    
          
    生成しない
    • シーンファイルの自動編集
    • 入力の成功・失敗判定
    • 音源や視覚素材そのもの
    • Godot 3・他エンジン用コード
    
        
    
        
    1つのAudioStreamPlayerを共有するため、連続操作では前の音を止めて次の音を再生します。多重再生やミュート設定はアプリ側で設計してください。フォーカス移動にはButton側のfocus_modeとナビゲーション設定も必要です。
    
      
    

      
    
        
    03 / TEST ASSETS
    
        
    無料素材で配線を確認
    
        
    生成機能は購入なしで使えます。視覚フィードバックは無料SelectionでAPIを確認でき、音源は無料2音でAudioStreamPlayerへの割当を試せます。成功・無効の3効果版と8音版は各500円です。
